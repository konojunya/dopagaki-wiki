## 音声と再生

- VOICEVOXずんだもん/ノーマル、61文すべて非無音。元PCMのクリッピング0サンプル。`review/audio-check.json`。
- ENGINEのカナ列を調べ、「負」「値」「京」の読み違いを修正。「ふ」「あたい」「けい」に変わったことを確認。
- ローカルのWhisper smallで全編を転写し、原稿と主要な値・説明の流れを照合した。ASRには「Go→5」「uint→有印」「符号→不合」のような同音・専門語の転写誤りが残る。自動一致率を読みの正確さと見なさず、疑義のある語をENGINEカナと突き合わせた。
- 音量を約−25.8LUFSから、完成MP4で−16.38LUFSに調整。AAC化後のtrue peakは−1.09dBTP。
- 368.000秒、11,040フレーム、1080p/30fps/H.264/AAC。音声・映像・コンテナの尺が共通タイムラインと一致。全編デコード成功。
- MacのGoogle Chromeで、冒頭・中間2箇所・末尾をseekして再生時間とデコードフレームの進行を確認。`review/playback.json`。

人による試聴は行っていない。音響検査・カナ列・ASR・ミュートでの実再生を実施したため、自然な抑揚や好みまで確認済みとはしない。短文分割は意味の通る文の単位で保ち、句の途中で分けていない。
