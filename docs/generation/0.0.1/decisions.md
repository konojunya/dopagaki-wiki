# 実装と決定事項

## 責務

エージェントは調査、根拠の読解、原稿、図解の意味、内容のレビューを担当する。CLIはランタイムschema、レイアウト、文字・画像の描画、音声生成、サンプル単位の時間管理、字幕・動画合成、機械検査を担当する。生成中にLLM APIは呼ばない。

これにより、モデルが変わっても文字サイズや字幕位置、色、時間計算、失敗条件は同じになる。意味的な正確さや説明の深さはモデルの能力に影響されるため、学習項目と根拠の対応、詳細な入力schema、実行済み例、レビュー基準をSkillに持たせた。別モデル同士の比較実験は未実施。

## 固定した表現

横長16:9、1920×1080、30fps。背景は白、緑一系統とニュートラル。DADS Green-900/Green-50とNoto Sans JP/Monoを採用。タイトル64px、本文48px、コード40px、字幕48px。字幕の行は本文とは別に確保する。DADSのWeb向け文字スタイルを動画サイズへ拡大した対応はSkillのdesign-system.mdに記録した。

意味を持つ図をDOM、SVGで描く。必要なら画像生成を使い、ロゴは公式配布元から取得する手順をSkillに明記。`visual` レイアウトはPNG/JPEG/WebP/自己完結SVGと入手元を受け取る。整数型の本編ではビット列、比較表、コード、手順をDOMで描いた。補助試作でSVG取り込みも実行した。画像生成やロゴ取得を本編で実施する必要はなかった。

## 音声と字幕

VOICEVOXの話者IDを固定値にせず名前・スタイルから解決。初期はずんだもん/ノーマル。音声を1文ずつ逐次生成し、48kHz mono PCMのサンプル数を計測してから結合する。1フレーム=1600サンプルで切り上げ、前後各1秒の無音を含めた同じ時刻を字幕と映像に使用する。ENGINEの前後音素長は0.08秒/0.12秒。

字幕はnarration.textからのみ生成する。表示上の改行を除いて原稿と一致。発音辞書は合成用テキストだけに適用し、共有ユーザー辞書は変更しない。字幕制御文字となるバックスラッシュ/波括弧は発話原稿では拒否し、リテラルコードは画面のcode欄に置く。

最初の音声では「負=まけ」「値=ね」「京=きょう」を検出した。ENGINEのカナ列でも確認し、「ふの」「あたい」「けい」を指定して修正した。型名も長い一致を先に置換する。8桁のゼロを連続して読む箇所は、図の位の重みを説明する文に変更した。

原音のintegrated loudness約−25.8LUFSは小さかったため、2パスのloudnormで−16LUFS、true peak−1.5dBTPを目標に調整。AAC化後の実測は−16.38LUFS / −1.09dBTP。検査の許容域は−18〜−14LUFS、true peak−0.5dBTP以下。無音・クリッピング・各文の音声欠落を別に検査した。

## 映像と速度

各スライドはChromiumで一度撮影し、FFmpegで静止画のフレームを補間してからASSを描画する。`fps=30 → ass → encode` の順序が重要。最初の試作では出力側でフレーム複製したため、尺の不一致を機械検査が検出した。順序を修正し、実FFmpegのテストで34秒の尺と字幕の出入りを検証した。

libx264 ultrafast / CRF23、AAC128kbps。TTSは逐次1で初回57秒を実測できたため、並列TTSやRemotionは追加していない。調査時間を含む「質問から57秒」とは主張しない。

音声・画像・動画をハッシュでキャッシュ。原稿の1文だけを変えると、その音声と後続タイムライン・動画を更新する。見た目の変更では音声を使い回す。声、速度、辞書全体、ENGINE/モデル、ENGINE共有辞書のハッシュも音声キーに含む。画像はHTML/CSS・フォント・画像素材・Chromiumの情報で識別する。

原子的な素材書き出しとチェックサムで途中再開する。破損したWAVを入れた検証では、その1文を再生成して復旧した。完成動画は尺・デコード・音量の検査を通ってからキャッシュへ登録する。

## 導入と保存

Node、FFmpeg/ffprobe、検算用Go、任意の音声認識QA用uvをaqua.yamlに記録。PlaywrightとそのChromiumはnpmのlockfileと対応ビルドで固定。Playwright 1.55.0の既知のダウンロード検証問題をauditで検出し、1.55.1に更新した。最終auditは0件。

CLIをリポジトリ外で使うとaquaの設定探索が変わるため、FFmpeg/ffprobeをこのリポジトリ内で `aqua which` してから呼び出す。Skillはシンボリックリンクでインストールし、入口が実装を確実に見つけるようにした。任意cwdからの外部出力で実行検証した。

動画は16.2MBなのでGitに含める。中間WAV、キャッシュ、各字幕検査の切り抜き全件は除外し、結果JSON・代表フレーム・最終MP4を保持する。Git LFSは使用していない。
