全ページの表示、焼き込み字幕、全編デコード、実動画再生、音声波形と発音データを確認。人による試聴・ASR・モデル間比較は未実施。詳しくは [品質確認](quality-review.md) と [比較条件](comparison.json) を参照。

## 再生成

リポジトリのルートで、セットアップ済みの環境から実行する。出力先は自動で新しい `/tmp` ディレクトリになる。保存済みの動画は上書きしない。

```sh
npm run cli -- render docs/generation/0.0.1/20260908T225140Z-repository-walkthrough/story.json
```

現在の実装が生成時から変わっている場合、同じ見た目やハッシュになるとは限らない。生成時の実装・依存・デザイン・音声エンジン情報はmanifest.jsonに記録している。

## 速度の記録

[benchmark.json](benchmark.json) に4条件を各1回保存。初回は音声と動画が未キャッシュで30.159秒、変更なしの再実行は4.158秒。初回も画像はプレビューから再利用しており、完全なコールド実行ではない。調査・原稿作成・確認時間は含まない。

表示だけの修正は音声28/28、1文修正は音声27/28を再利用。これらは最終的な発音修正前の比較であり、各入力とmanifestをbenchmarks/に残した。

## 保存を省略したもの

中間WAV、キャッシュ、重複フォント、全スライドPNG/HTML、字幕検査用の全画像、比較途中のMP4は省略。入力画像・台本・実行条件・機械検査結果・全ページ一覧・代表フレームを保存し、通常の生成物を一括でGit管理する運用にはしない。
