# デジタル庁デザインシステムに準拠する

2026-09-09 に DADS v2.17.1 のカラー、タイポグラフィ、余白を確認した。実装は `src/theme.ts`。カラーやフォントを story ごとにモデルが自由生成する構成にはしない。

- [カラー](https://design.digital.go.jp/dads/foundations/color/): 緑の同系統とニュートラル色を使う。Green-900 `#115a36`、Green-50 `#e6f5ec`、白、本文 `#1a1a1c`、補助文字 `#4d4d4d`。区切り線は `#808080`。
- [タイポグラフィ](https://design.digital.go.jp/dads/foundations/typography/): Noto Sans JP と Noto Sans Mono。太さ400/700を使う。フォントを同梱し、ライセンスも保持する。
- [テキストスタイル](https://design.digital.go.jp/dads/foundations/typography/text-style/): タイトル・大見出しは Dsp-64B-140、本文は Std-24N/B-150 の2倍、コードは Mono-20N-150 の2倍、字幕は Dsp-48N-140。動画としての視認性を満たすため、1080pで大きく使う。
- テキストは背景に対して4.5:1以上、意味を持つ境界や図形は3:1以上を確保する。符号・良否・種類を色だけで伝えない。
- 固定キャンバスは1920×1080。内側余白は左右96、上48、下32。通常フロー、Grid、Flexのみで配置する。本文と字幕は独立した行に置く。

DADS は Web 向けの設計なので、動画に存在しないフォーム等のコンポーネントは持ち込まない。準拠する基礎仕様と動画向けの拡大・字幕領域は上記のように区別する。DADSによる認証・推奨を意味しない。

## レイアウト選択

| layout | 適した説明 |
|---|---|
| key | 結論、3点以内の要点 |
| compare | 2〜3列、4行以内の比較 |
| flow | 2〜3段階の手順や処理 |
| code | 短いコードと実行結果・注意点 |
| example | ビット列など最大8セルと式 |
| visual | SVG・ダウンロード画像・生成画像と説明 |

要素数の上限は収まる保証ではない。長い日本語、識別子、表、コードを実際にプレビューして判断する。文字を縮めず、内容を分ける。横向きスマートフォン相当の844×475でも確認する。縦向き画面内の小さな16:9表示では細部を読めるとは保証せず、横向き全画面を想定する。

図はDOMかSVGで正確に描く。創造的な説明素材は画像生成を選んでもよい。ロゴは公式配布元から取得し、生成で模倣しない。画像は外部参照やスクリプトなしのローカルファイルにし、元URL・生成プロンプト・説明を asset.origin に記録する。
